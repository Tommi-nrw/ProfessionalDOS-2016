Professional DOS was the fastest floppy speeder (excluding RAM disk setups)
for the Commodore 64 / 128 and 1541 / 1571 back in the '80s.
It was sold as RapiDOS in the US and DISK DAEMON in the UK.

This is an upgraded version of the rebuilt Professional DOS.

The PCB works with both the 1541 and 1571. 
In the 1541, the board also lets you switch between Professional DOS, SpeedDOS, and DolphinDOS.
